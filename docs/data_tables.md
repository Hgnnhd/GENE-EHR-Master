# 派生数据表与质控规则

所有患者级表位于 `data/processed/`，仅供本地研究。汇总统计不包含参与者 ID。

| 表 | 行单位 | 用途 |
|---|---|---|
| participants | 参与者 | 性别、出生月份、招募、死亡/失访、患者划分、首癌及覆盖状态 |
| events | 参与者 × ICD10 三级码 | 两来源最早可靠日期，同时保留各来源日期与来源标志 |
| cancer_events | 原始癌症登记 Instance | 保留原始日期和两套编码、派生癌种与质控状态 |
| self_report_cancer | 自报癌症 Instance × Array | 原始编码/名称、诊断年龄/年份、评估日期、编码类别 |
| landmark_status | 参与者 × 预测点 | 包括所有排除者的互斥首个排除原因 |
| landmark_samples | 通过临床筛查者 × 预测点 | 候选资格、登记覆盖、结局状态、逐癌种标签和病史数量 |
| features_asof | 候选者 × 预测点 | 最近一次预测点前的风险因素；各字段带时间、Instance、缺失标志 |
| pretrain_participants | 训练参与者 | 内部预训练训练/验证角色，含无记录者 |
| pretrain_events | 训练参与者 × 首次医疗代码 | 日期 < 2016-01-01，带预训练角色 |
| quarantine | 异常源记录 | 患者级异常记录与来源，便于修复后重新构建 |

## 关键语义

`clinical_candidate=true` 表示通过招募、存活、失访和既往癌症筛查；只有覆盖资料核实且覆盖预测点后才有 `eligible=true`。未核实覆盖不等于没有癌症。

`followup_status` 取值包括 `coverage_unverified`、`not_observable_at_landmark`、`cancer`、`death`、`censored`、`event_free_5y`、`event_loss_tie_unresolved`、`ineligible`。删失和未核验记录的五年标签为空。死亡和其他癌症保留独立事件类型；对某癌种的五年累积发生指示为 0，不作为普通失访删失。生存模型须同时读取事件类型和观察时间。

覆盖日期统一为 `[registry_start, registry_end_exclusive)`。目标窗口为 `[t0,t0+5年)`；输入为 `<t0`。癌症和死亡同日视为该日癌症事件并保留同日标志；癌症/死亡与失访同日则结局待核验。多癌种同日首发保存为 `first_cancer_sites` 的完整集合，允许多个目标阳性。

`observed_*_5y` 只描述满足候选规则、窗口内已见的登记首癌；它没有证明对照者被完整随访，不可直接替换 `label_*_5y`。

## 已执行的保守质控约定

1. 住院代码数与日期数不一致时隔离该人的整组住院配对，不尝试重排日期。其余来源可用；若异常记录包含恶性肿瘤，则标记癌症病史待核验。
2. 事件日期早于出生月份起点、晚于死亡，或日期无法解析，隔离后再按三级码取最早有效日期。不会因无效的最早日期而丢掉另一来源的有效日期。
3. 癌症登记日期或编码缺失/无效、早于出生或晚于死亡时，保留原条目并暂缓该参与者节点资格；死亡日期多源冲突同样暂缓。异常可能发生于后期，此规则是全记录完整性质控，人数单列。
4. 自报采用本地 UKB `data_coding_3` 字典。1060、1061、1062、1073（非黑色素瘤皮肤癌分支）及 1072（宫颈癌前病变）不作为既往浸润癌。1003（未分型皮肤癌）、1051（骨髓纤维化/骨髓增生异常）、99999 和字典外值暂列含义待核验。
5. 自报只有评估日期早于预测点才参与已知病史排除，诊断年龄/年份保留供复核，不把估算年份伪装为准确日期。后续采集的自报暂不反推早期节点；日期未知的潜在恶性肿瘤自报单列待核验。
6. EHR-only 事件不加入癌症登记或自报标签来补历史。未出现某代码表示文件无已知首次事件，不等于没有病史。
7. 增强特征按每个字段最近非缺失且预测点前的评估选取；拒答/不知道视为缺失，Townsend 等连续变量保留合法负值。尚未拟合标准化或数值插补。

这些约定用于当前初版；改变编码解释或放回隔离病例应更新协议并重新生成病例流程。
